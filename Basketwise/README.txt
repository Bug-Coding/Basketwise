BASKETWISE — HOSTING PACKAGE

This folder contains the complete static website. Upload the contents of this folder to the root of any static web host. Keep the folder structure, especially images/ and icons/.

HTTPS hosting is required for browser installation and offline caching. Static hosts such as GitHub Pages, Cloudflare Pages, Netlify, or a regular HTTPS web host can serve this folder. No server or database is required. Grocery lists and preferences are saved in each visitor's browser.

INSTALL ON ANDROID / CHROME
1. Open the hosted HTTPS website in Chrome.
2. Use the browser menu and choose “Install app” or “Add to Home screen”.
3. Open Basketwise from the new home-screen icon.

INSTALL ON IPHONE / IPAD
1. Open the hosted HTTPS website in Safari.
2. Tap Share, then “Add to Home Screen”.

The website also works directly in modern desktop and mobile browsers. This package installs as a browser-based PWA; it is not an Android APK or a Google Play Store listing.
